📡 数据来源

全部来自 api.zuhaome.com/api/v1/ 的公开接口，无需登录：/games、/categories、/announcements、/faqs、/membership/plans、/client-download。抓取时点见仓库提交记录。

🚫 为什么不做在线查询

上游 API 返回 {"error":"CORS origin not allowed"} 403，浏览器跨域直连被拒。所以这里只放静态快照，不做实时查询。

🖥️ 客户端 exe

官方客户端 ZuHaoMe-1.1.1.exe 由 /api/v1/client-download/file 下发；本仓库 client/ 另存了一份，Release 里也挂了直链。

🔧 源码与接口文档

src/MainForm2.cs 是客户端反编译还原（117KB，含登录/下单/心跳逻辑）；api/ 下有完整接口清单与 OpenAPI 导出。
